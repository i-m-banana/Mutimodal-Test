# 朗读文本配置说明

## 📖 功能说明

测试页面的**朗读录音**阶段现在要求用户朗读指定的文本内容，系统会对朗读过程进行录音。

## 🔧 如何更改朗读文本

### 方法一：修改配置文件（推荐）

编辑文件：`config/reading_texts.yaml`

```yaml
# 默认使用的文本（索引从0开始）
default_text_index: 0  # 修改这个数字来切换默认文本

# 朗读文本列表
texts:
  - id: "aviation_safety"
    title: "航空安全规范"
    content: |
      乘员应在进入航空器前，接受安检并配合现场工作人员的引导...
      
  - id: "funny_stories"
    title: "幽默小故事"
    content: |
      聪明的儿子：父亲对儿子说："这里是五步蛇，被它咬了走五步就死。"...
```

**快速切换文本：**
- 将 `default_text_index` 改为 `0` → 使用第一段文本（航空安全规范）
- 将 `default_text_index` 改为 `1` → 使用第二段文本（幽默小故事）
- 将 `default_text_index` 改为 `2` → 使用第三段文本（健康小贴士）

**添加新文本：**
```yaml
  - id: "my_custom_text"
    title: "我的自定义文本"
    content: |
      在这里输入您想要用户朗读的文本内容...
      可以分多行输入...
```

### 方法二：直接修改代码（不推荐）

编辑文件：`ui/app/pages/test.py`

找到 `__init__` 方法中的默认文本部分：

```python
self.reading_text_title = "航空安全规范"
self.reading_text_content = """乘员应在进入航空器前，接受安检并配合现场工作人员的引导...
"""
```

直接修改 `self.reading_text_content` 的内容即可。

## 🎯 使用流程

1. 用户进入测试页面的"朗读录音"阶段
2. 页面显示完整的朗读文本（可滚动）
3. 用户点击录音按钮
4. 用户清晰地朗读屏幕上的文本
5. 朗读完成后点击停止按钮
6. 系统保存录音并进入下一阶段

## ⚙️ 技术说明

- 文本配置文件使用 YAML 格式，支持多行文本
- 文本内容会在 UI 中以可滚动的文本框显示
- 系统会自动记录朗读开始和结束的时间戳
- 录音文件保存在 `recordings/{username}/{timestamp}/fatigue/` 目录下

## 🔄 修改后如何生效

修改配置文件后，**重启应用程序**即可生效，无需重新编译。

## 📝 注意事项

1. 文本内容不宜过长，建议控制在 200-500 字以内
2. 文本应该清晰易读，避免生僻字和复杂句式
3. 如果配置文件读取失败，系统会自动使用默认文本（航空安全规范）
4. 修改配置文件时请保持 YAML 格式的正确性（注意缩进）
