# 多模态人员状态评估平台

基于事件驱动架构的多模态数据采集与分析平台，集成 EEG 脑电、RGB 视频等传感器，用于非接触式人员疲劳度、情绪状态与认知负荷评估。

## 🎯 核心功能

### 疲劳度评估
- **评估策略**: EEG (70%) + RGB (30%) 加权融合，支持自适应权重调整
- **RGB 疲劳检测**: 基于RGB、深度、眼动数的面部疲劳特征深度学习推理
- **EEG 疲劳分析**: 基于脑电信号的疲劳度机器学习推理

### 情绪评估

- **评估策略**: 综合语音、文本与视频特征进行深度学习判别
- **语音**: 将预处理后的音频特征传入语音模型进行声学情绪特征抽取。
- **文本**: 将经由faster-whisper转写的文本传入预训练的文本编码器提取语义情绪信息。
- **视频**: 使用基于时间序列的视频模型提取表情与面部动作单元相关特征。

### 脑负荷评估

- **评估策略**: 基于EEG信号，通过时域/频域与非线性特征回归模型进行评估：
- **采样与预处理**：滤波、伪迹去除、分段与基线校正。
- **特征工程**：计算各频段能量、功率比、熵等，并使用特征选择降低维度。

### 生理数据采集

- **血压/心率**（通过 maibobo 或串口血压计驱动）
- 所有采集的数据（音频、视频、EEG、眼动、血压）按会话保存到 `recordings/{username}/{timestamp}/` 目录，便于离线分析与复现。

### 专注度测试

- **SART**：持续注意任务，用于评估持续注意力与冲动失误率，支持短/长两种时长配置。
- **舒尔特方格**：评估视觉注意与处理速度，记录用时与准确率用于综合评分。

### 总结面板
- 实验结束后，系统会把各阶段（基线、SART、朗读、血压、舒尔特）的结果汇总到会话数据并通过 UI 展示。

## 🚀 快速开始

本仓库的详细启动、配置、日志与常见问题说明已移至 `QUICK_START.md`（位于仓库根目录）。请打开该文件获取逐步的安装、启动与故障排查指南。

**方式一：一键启动（推荐）**

双击 `start.bat` 或在项目根目录运行：
```powershell
start.bat
```

**方式二：手动启动**

```powershell
# 终端1 - 启动后端
python -m src.main

# 终端2 - 启动前端
python -m ui.main
```
